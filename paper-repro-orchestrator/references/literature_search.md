# 文献与代码源调查模块

## 目标

查清论文身份、官方来源、作者代码、数据集、第三方复现、相关方法和依赖风险，输出 `outputs/literature_sources.md`。

## 流程

1. 根据论文标题、PDF 元数据、arXiv ID、DOI 或 URL 确定论文身份。
2. 联网搜索官方论文页、arXiv/出版社页、作者主页、GitHub/GitLab 代码库、数据集页。
3. 查找第三方复现和相关方法，但标注可信度，不把非官方实现当成论文事实。
4. 检查代码库入口、依赖、许可证、最近更新时间、数据和预训练权重。
5. 在报告中提供链接和来源类型。

## 输出字段

- 来源名称和链接。
- 来源类型：官方论文、作者代码、数据集、第三方复现、相关方法、依赖文档。
- 可用性：可访问、缺失、需登录、依赖重、代码不完整。
- 对复现的作用。
- 引用注意事项。

## 约束

- 必须联网确认可能变化的信息。
- 技术实现优先参考论文、官方文档和作者代码。
- 打开来源核对，不直接相信搜索摘要。
