# 论文精读与复现规格模块

## 目标

精读论文，提取问题定义、公式、算法、模型假设、实验参数、图表、指标、数据集和复现边界，输出 `outputs/reproduction_spec.md`。

## 流程

1. 读取 PDF 文本、页数、标题、摘要、章节、图表和算法。
2. 提取问题定义、符号、公式、模型假设和算法步骤。
3. 提取实验设置：数据、随机种子、参数、训练设置、评价指标、表格和图片。
4. 判断复现范围：完全复现、趋势复现、功能复现、替代实现。
5. 写出后续代码实现契约。

## 必须写清

- 输入、输出、核心任务。
- 需要实现的基线和论文方法。
- 每张表、每张图的复现方式。
- 可运行命令和预期产物。
- 随机性、数据缺失、依赖缺失造成的差异风险。

## 脚本

- `scripts/extract_pdf_text.py`：从 PDF 抽取文本到 stdout 或文件。
